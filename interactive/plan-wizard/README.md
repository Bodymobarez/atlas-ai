# معالج البلان التفاعلي — Atlas Plan Wizard

أسئلة **سؤال سؤال** مع اختيارات تُضغط بالماوس.

## التشغيل

من جذر الريبو:

```bash
# أي سيرفر محلي بسيط
cd interactive/plan-wizard
python3 -m http.server 8765
```

ثم افتح: [http://localhost:8765](http://localhost:8765)

أو افتح `index.html` مباشرة في المتصفح (يُفضّل عبر سيرفر محلي).

## الاستخدام مع الشات

1. بعد **Idea Research** افتح المعالج  
2. جاوب بالضغط على الاختيارات  
3. في الآخر: **نسخ للشاحات**  
4. الصق الناتج في شات Atlas  

لو ظهر `PLAN_LOCK: اعتمد البلان` يكمل الوكيل سلسلة التنفيذ.

## للمحترفين / الوكلاء

- بنك الأسئلة: `questions.js`  
- يجب على Interactive Planner تفضيل هذا الـ UI  
- إن تعذّر: اعرض نفس الاختيارات في الشات **سؤال واحد فقط** وانتظر
