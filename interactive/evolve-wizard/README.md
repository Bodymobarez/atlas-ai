# معالج خطة التطوير — Evolve Wizard v2

واجهة تفاعلية لتخطيط **تطوير مشروع قائم** (مش بناء من الصفر).

## التشغيل

```bash
cd interactive/evolve-wizard
python3 -m http.server 8766
```

افتح: [http://localhost:8766](http://localhost:8766)

## ماذا في v2؟

- شاشة طلب التطوير + قيود قبل الأسئلة  
- **18 سؤال** عبر قطع: هدف / نطاق / أسلوب / أسطح / مخاطر / UI / بيانات / جودة / تحقق / اعتماد  
- اختيار بالماوس + اختصارات لوحة المفاتيح (A–G، Enter)  
- أسئلة **متعددة الاختيار** (خارج النطاق، الأسطح، الجودة)  
- شارة **موصى** على الخيارات الأفضل افتراضيًا  
- تخطي أسئلة UI لو اخترت «لا UI»  
- شريط قطع للتنقّل  
- تصدير: نسخ للشات + `CHANGE_PLAN.md` + JSON  
- استيراد JSON سابق  
- حفظ تلقائي في المتصفح  

## بعد الإنهاء

1. اضغط **نسخ للشاحات**  
2. الصق في شات عليه `AUTO_EVOLVE` / جملة `OPEN_IN_CHAT_EVOLVE.md`  
3. لو ظهر `EVOLVE_LOCK: اعتمد خطة التطوير` يكمل التنفيذ
