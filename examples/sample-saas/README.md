# Example — Sample SaaS Run (Illustrative)

This folder shows **what artifacts look like after Consultant + early Master planning**. It is fictional and incomplete on purpose for teaching structure — do not copy business content into a real product.

## Imaginary product

**Name:** Northstar Attendance  
**Type:** `WEB_APP` + light `MOBILE_APP` later  
**MVP Promise:** A manager can create a shift, employees can check in, and the manager can export today’s attendance.

## Expected artifact sequence

1. `docs/discovery/BRD.md` + `VISION.md`  
2. Master `PLAN.md` with `BLOCKED_NO_CODE`  
3. Discovery → Research → BA → PM → Architect  
4. G8 only after baselines  

## Lesson

Even a “simple attendance app” still gets security (authZ), a11y, tests, and monitoring by default under Atlas AI.

See sibling stub files in this folder for shape only.
